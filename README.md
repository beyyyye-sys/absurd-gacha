# 离谱制造局 · 荒诞扭蛋实验室

一个不收钱、只收集怪东西的赛博街机扭蛋游戏。拉下拉杆，把「量子摸鱼终端」「永不调休的星期六」之类的离谱收藏品带回家。

**纯 HTML / CSS / 原生 JavaScript，零第三方运行依赖、零外部 API、无需构建，可以直接部署 GitHub Pages。** 插画使用本地 SVG / CSS，音效由浏览器 Web Audio 合成，没有图片、字体或音频 CDN 请求。

## 开始游戏

在这个文件夹内启动静态服务器：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173>。安装了 npm 时，也可运行 `npm start`；该命令仍使用 Python 3，不需要执行 `npm install`。

请通过 HTTP(S) 访问，**不要直接双击 `index.html`**。项目使用 ES Modules，浏览器通常会限制 `file://` 下的模块加载。

推荐当前版本的 Chrome、Edge、Firefox 或 Safari，支持桌面和手机。浏览器需要支持 ES Modules、原生 `<dialog>`、CSS `color-mix()` 等现代网页能力。

## 有什么可玩

- **拉杆抽奖**：点击机器拉杆或「扭一个试试」，观看搅蛋、出货和揭晓动画。页面主体获得焦点且没有弹窗时，可按空格抽奖；按钮本身也支持键盘操作。
- **十连抽奖**：一次展示 10 件结果，并保证至少一件「稀有」或更高级藏品。
- **72 件原创常规藏品 + 4 件隐藏彩蛋**：每件都有名称、编号、类别、短标签和独立搞怪说明。隐藏藏品不进入普通奖池，不占常规 72 件完成率。
- **收藏图鉴**：未发现藏品保留问号；已发现藏品可查看详情与拥有数量。可按稀有度筛选、搜索已发现藏品、只看已收集。
- **抽奖记录**：保留最近 200 条获得记录，包括彩蛋；累计次数和收藏数量不会因历史截断而清空。
- **12 个成就**：首次抽奖、10 / 50 / 100 抽、重复物品、收藏 10 / 30 / 全部 72 种、获得史诗 / 传说、触发 3 个彩蛋，以及首次十连。
- **本地存档**：自动保存收藏、数量、保底计数、抽奖历史、成就、彩蛋和音效 / 动画设置。支持 JSON 导出、导入和二次确认重置。
- **音效与无障碍交互**：音效默认关闭，右上角 `♪` 可切换；支持「减少动画」和系统减少动态效果偏好，提供键盘焦点样式与抽奖结果播报。

## 概率与保底

以下为每次普通抽奖的**基础稀有度概率**。选定稀有度后，在该级别的常规物品中等概率抽取。

| 等级 | 代码 | 基础概率 | 常规物品数 |
| --- | --- | ---: | ---: |
| 普通 | `common` | 50% | 28 |
| 不凡 | `uncommon` | 28% | 20 |
| 稀有 | `rare` | 15% | 12 |
| 史诗 | `epic` | 6% | 8 |
| 传说 | `legendary` | 1% | 4 |

- **60 次传说保底**：连续 59 次没有获得传说，第 60 次必定传说；任何一次普通池传说都会将该计数归零。单抽和十连共享计数。
- **十连保底**：如果前 9 次都低于稀有，第 10 次从稀有 / 史诗 / 传说中按原基础权重重新归一化抽取。不会替换已获得的前 9 件。
- 传说保底优先于十连保底。因此实际长期概率会受保底提升，不能把表中基础概率当作包含保底后的最终频率。
- 重复藏品增加拥有数量，不转化为货币；游戏无体力、付费抽奖、充值或真实交易。
- 隐藏彩蛋每种只可领取一次，不增加普通抽奖次数，也不改变传说保底计数。

## 存档与离线边界

点击右上角齿轮可管理存档。**导入会替换当前游戏进度，不会合并**；先导出备份再换档。

| localStorage 键 | 用途 |
| --- | --- |
| `absurd-gacha-save-v1` | 当前游戏主存档 |
| `absurd-gacha-save-v1-corrupt-backup` | 读取到损坏存档时，保留原始内容供恢复 |
| `absurd-gacha-before-import` | 导入前旧进度的尽力备份 |

存档属于当前浏览器的当前源（协议 + 主机名 + 端口），不会上传服务器。`localhost` 与 `127.0.0.1`、不同端口、HTTP 与 HTTPS、不同浏览器或设备之间均不共享存档；同一 GitHub Pages 域名下使用本游戏存档键的其他实例可能共享数据。需要迁移时请导出 JSON，再到目标环境导入。

- 导入限制为 2 MB，校验 JSON、版本、藏品 ID、计数、历史、彩蛋和数据一致性；无效文件会提示失败，保留当前进度。
- 存储被禁用或空间不足时，游戏可在内存中继续，但刷新后可能丢失新进度，应及时导出。
- 如果原存档损坏，程序先保存原文备份，再允许新进度覆盖主存档；若备份也失败，会暂停自动保存以保护原始数据。
- 导入前备份受浏览器存储限制，不能替代用户主动下载的备份。重置需要二次确认，清空后不能在游戏界面撤销。
- 隐私模式、清理站点数据和浏览器卸载都可能删除本地存档；没有账号、云同步或服务端恢复功能。
- 页面载入后，抽奖、图鉴、音效和存档逻辑都在本地运行，不需要外部网络服务。本项目没有 Service Worker / 安装式离线缓存：断网时重新访问线上页面，不保证可打开。运行本地静态服务器可在没有互联网连接的环境使用。
- 这是单机娱乐游戏，随机数使用 `Math.random()`；存档和代码可被本机用户修改，不用于公平竞赛、价值兑换或安全认证。建议一个标签页游玩，避免多个页面同时抽奖造成覆盖。

## 部署到 GitHub Pages

以下使用 GitHub 的分支发布，不需要 Actions、服务器、API Key 或构建命令。

1. 在 GitHub 创建一个仓库，例如 `absurd-gacha`。普通 GitHub Free 账号可使用公开仓库发布 Pages；私有仓库的 Pages 可用性取决于账号方案。
2. 将**本文件夹内部的内容**作为仓库根目录上传 / 提交，而不是仅上传一个 `cyber-gacha` 外层目录。仓库根应直接出现 `index.html`、`styles.css`、`app.js`、`engine.js`、`catalog.js`、`icons.js`、`favicon.svg` 和 `.nojekyll`。README、package.json 和测试可以一起提交。
3. 推送到 `main` 分支后，在仓库打开 **Settings → Pages → Build and deployment**。
4. 将 **Source** 设为 **Deploy from a branch**，分支选 **main**，目录选 **/ (root)**，保存。
5. 等待 GitHub Pages 发布完成，打开设置页显示的站点链接。普通项目仓库通常是 `https://你的用户名.github.io/absurd-gacha/`；以 GitHub 实际显示地址为准。

GitHub Pages 的分支来源目录只提供根目录或 `/docs` 等支持的选项；**不能直接选择当前交付路径 `outputs/cyber-gacha` 作为发布目录**。按照以上步骤把其内部文件置于仓库根目录即可。所有资源使用 `./` 相对路径，适用于项目仓库子路径。

`.nojekyll` 已提供，告知 Pages 按静态文件处理。本交付只包含可发布的代码与说明，**没有替你创建 GitHub 仓库或实际部署**。

遇到 404 时，先确认 `index.html` 位于发布源根目录、Pages 分支选择正确、发布任务完成；不要把本地 `file://` 或 `127.0.0.1` 地址当作线上链接。

## 验证

需要 Node.js 18 或更新版本，无需安装任何 npm 依赖：

```bash
npm test
```

也可直接运行：

```bash
node --test tests/engine.test.mjs
```

引擎测试覆盖概率边界、60 抽传说保底、十连保底、重复收藏、历史上限、彩蛋去重、成就、导入导出、存储失败、损坏存档保护和不可变状态更新。它们不依赖外部网络。

本次实际验收：18 项引擎测试与 33 项 Chromium 页面检查通过；桌面及 360 / 390 / 768 像素布局无横向溢出，未捕获浏览器脚本错误，未发现外部资源 / API 请求。详见 [TEST_REPORT.md](./TEST_REPORT.md)。

可选的完整页面回归测试（建议 Node.js 20 或更新版本；仅开发验证需要 Playwright，游戏运行仍零依赖）：

```bash
# 先在另一个终端启动 npm start
npm install --no-save --package-lock=false playwright
npx playwright install chromium
npm run test:browser
```

测试使用全新、隔离的浏览器配置，覆盖抽奖、收藏、全部四个彩蛋、导入导出、重置、历史、成就、设置与响应式布局。截图和结果保存在 `tests/artifacts/`，已加入 `.gitignore`。可用 `GACHA_TEST_URL` 指向其他测试服务器。没有运行跨浏览器测试。

界面人工验收建议：拉杆单抽 → 十连 → 图鉴筛选与详情 → 历史 → 成就 → 开关音效 → 减少动画 → 刷新确认存档 → 导出后导入 → 重置取消 / 确认，并分别检查桌面与手机宽度。
